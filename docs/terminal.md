# Терминальный интерфейс

`reviewctl` открывает рабочее пространство на весь терминал: задачи слева, выбранная сессия справа, поле ввода снизу. Интерфейс работает через тот же API, что и сайт. Он не запускает отдельного агента и не требует tmux.

![Разговор с ревьюером](media/cli-chat.png)

## Запуск

```bash
reviewctl
reviewctl console <task-id-or-prefix> --role reviewer
reviewctl --theme light
reviewctl --url https://review.example.com
reviewctl --plain
```

В широком окне видна панель задач. При ширине меньше 110 колонок она скрывается; задачи остаются доступны через Ctrl+T. Минимальное окно — 50 × 20. Простой режим также выбирается автоматически для TERM=dumb и терминалов без интерактивного ввода/вывода. Отдельные CLI-команды сохраняют обычный вывод для скриптов.

## Клавиши

| Клавиша                 | Действие                                                           |
| ----------------------- | ------------------------------------------------------------------ |
| Enter                   | Отправить сообщение; выполнить набранную команду; выбрать пункт    |
| Tab                     | Переключить автора и ревьюера; в меню `/` — дополнить команду      |
| Ctrl+T                  | Открыть поиск задачи по названию, репозиторию или ID               |
| ↑ / ↓                   | Выбрать пункт меню; переместить курсор между строками ввода        |
| ← / →, Home / End       | Переместить курсор внутри ввода                                    |
| Ctrl+J                  | Добавить новую строку                                              |
| Shift+Enter / Alt+Enter | Добавить строку, если терминал передаёт модификатор                |
| PgUp / PgDn             | Прокрутить переписку, замечания, контекст или журнал               |
| Ctrl+A / Ctrl+E         | Начало / конец строки                                              |
| Ctrl+W                  | Удалить предыдущее слово                                           |
| Ctrl+U / Ctrl+K         | Удалить текст до начала / до конца строки                          |
| Esc                     | Закрыть меню или отменить подключение PR                           |
| Ctrl+C                  | Закрыть меню или очистить поле; если поле пустое — закрыть консоль |
| Ctrl+Q                  | Закрыть консоль сразу                                              |

Вставка поддерживает несколько строк и никогда сама не выполняет команду. Даже вставленный `/publish` считается текстом сообщения. Чтобы выполнить команду, набери её или выбери через меню `/`.

Черновик хранится отдельно для каждой пары «задача + роль» при переключениях. Неотправленные черновики живут в текущем клиенте и исчезают при его закрытии. Если ответ на отправку потерялся, текст восстанавливается у исходного получателя: сначала проверь переписку, затем реши, нужен ли повтор.

## Команды

Введи `/` для меню. Стрелки выбирают пункт, Tab дополняет его, Enter выполняет полностью набранную команду.

![Меню команд](media/cli-menu.png)

| Команда                          | Действие                                               |
| -------------------------------- | ------------------------------------------------------ |
| `/tasks`, `/use <prefix>`        | Выбрать задачу                                         |
| `/role author`, `/role reviewer` | Выбрать получателя сообщения                           |
| `/author`, `/reviewer`, `/chat`  | Открыть соответствующую переписку                      |
| `/findings`                      | Прочитать текущий снимок native-ревью                  |
| `/logs`                          | Посмотреть последние события и действия инструментов   |
| `/context`                       | Требования, PR, рабочий каталог и постоянные сессии    |
| `/publish`                       | Опубликовать завершённое ревью выбранной задачи        |
| `/pause`, `/resume`, `/retry`    | Управлять выбранной задачей на сервере                 |
| `/attach`                        | Указать PR/MR, абсолютный путь на сервере и требования |
| `/demo`                          | Создать демонстрационную задачу                        |
| `/refresh`, `/status`            | Обновить состояние и подключение                       |
| `/help`                          | Открыть справку                                        |
| `/quit`                          | Закрыть клиент                                         |

Публикация и переходы задачи проверяются сервером. Закрытие консоли не отправляет `/pause` и не прерывает агентов. После временного обрыва сети клиент повторяет чтение состояния; внешние записи автоматически не повторяются.

## Отображение

![Светлая тема](media/cli-light.png)

Текст переносится с учётом ширины символов; кириллица и составные эмодзи редактируются целиком. Заголовки, сообщения разных ролей и блоки кода оформляются отдельно. Управляющие последовательности терминала удаляются из внешнего текста.

Индикатор показывает активную или ожидающую сессию и последнее действие инструмента. Ответ появляется после завершения агентского сообщения. Это не интерфейс для просмотра скрытых рассуждений модели. В переписке показываются последние сообщения в пределах объёма отображения; полная история доступна на сайте и через `reviewctl show <id>`.

Интерфейс использует [Ink](https://github.com/vadimdemedes/ink), React и отдельную модель состояния клиента. При выходе восстанавливаются основной экран, курсор и режим ввода терминала. Снимки в документации записаны из настоящего PTY и воспроизведены через xterm.js; сама консоль уже выводит панели и цвета.
