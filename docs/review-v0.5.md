# Review 0.5.0

Full self-review covered interface localization, model-catalogue freshness, update notifications and explicit runtime selection. English/Russian UI copy is separate from stored task and conversation content. Preferences have a monotonically increasing version so a late status response cannot undo a language selection. Template aliases resolve before inserting task data; regression coverage prevents translated labels from swallowing placeholders or translating inserted names.

Model choices come from Codex app-server `model/list`, including pagination and supported effort values. Successful responses cache for five minutes; explicit refresh re-queries the CLI. Source metadata records the responding CLI version and retrieval time. Existing selected models are not silently replaced. A live read on the development host returned six available models from Codex 0.153.4.

The update monitor reads executable versions and stable package metadata. Registry failures remain visible as failures, with no false claim of being up to date. Telegram sends at most one notice per version/outcome, respects both notification switches, and preserves uncertain-send protection. Polling stops on shutdown. Unsupported engines remain diagnostic only; Claude is not offered as a selectable runtime.

Explicit runtime selection validates the local installation identity, checks running and queued work twice, probes initialize/model-list, and restarts only on a user command. Stable launcher paths are retained, including symlinks managed by native updaters. Failed restart restores the CLI setting while preserving other configuration changes. This probe does not run a paid agent turn or claim full future-protocol compatibility.

Validation: 141 unit/integration tests and six browser scenarios pass. Added tests cover both languages, task/draft preservation, stale preference responses, model-cache expiry/refresh, future model/effort IDs, numeric versions, native-updater symlinks, shutdown cancellation, notification deduplication, private-user language/model commands and configuration rollback. Browser checks cover language before login, reload, phone layout, catalogue refresh and the update panel. Existing native-review, publication, workspace and transport regression suites remain green.
