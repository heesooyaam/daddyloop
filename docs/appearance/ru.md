# Темы и текущий usage

Нажми **значок палитры** в верхней панели или на экране входа. Есть восемь тем:

| Светлые | Тёмные  |
| ------- | ------- |
| Лёд     | Графит  |
| Жемчуг  | Полночь |
| Мята    | Хвоя    |
| Сирень  | Слива   |

Режим **Как в системе** выбирает Лёд для светлого оформления и Графит для тёмного. Явный выбор сохраняется в этом браузере, переживает перезагрузку и синхронизируется между его вкладками. На телефоне можно выбрать другую тему. Смена цветов не меняет задачи, черновики, модели или настройки сервера.

Палитры сайта охватывают разговор, доску задач, диалоги, формы и вход. У терминала отдельные варианты: `daddy --theme dark` и `daddy --theme light`.

## Usage виден постоянно

Панель под заголовком показывает периоды квот Codex, процент остатка, время обновления и число доступных заработанных сбросов. Она видна на компьютере и телефоне, в том числе до выбора сессии. Квота аккаунта общая для Codex-агентов на сервере.

Названия периодов берутся из длительности, возвращённой CLI: недельная квота не называется пятичасовой. Недоступные или устаревшие значения помечаются; отсутствие данных не превращается в ноль остатка. Сервер кеширует чтение на минуту. В подробностях можно запросить обновление явно.

**Подробнее и сброс** открывает полный вид аккаунта. Подготовка сброса не тратит его: нужно отдельное подтверждение. При повторе используется тот же идентификатор запроса. Приложение не покупает кредиты, не тратит заработанные сбросы автоматически и не возобновляет агента только на основании процентов.

```bash
daddy limits
daddy limits reset
daddy limits reset --request REQUEST_ID --yes
```

После сброса квоты аккаунта разговоры и файлы сохраняются.
