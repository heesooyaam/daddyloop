# Arcadia и Tracker

При установке выбери модуль `arcadia`. Он использует корпоративные инструменты хоста: публичный установщик не ставит и не авторизует Arc/Arcanum за тебя.

```bash
daddy arcadia setup --help
daddy arcadia setup
daddy arcadia mounts
daddy workspaces add ~/arcadia2 --name Work --base trunk
```

Настрой подходящий этой машине helper `arcadia-mount-lease`. Его конфигурация задаёт общее хранилище объектов, диапазон mount'ов, резервы и папку lease. Mount должен использовать ожидаемый общий store. Зарегистрированная исходная папка, снимки сессий и исходники задач исключаются из распределения воркерам.

Воркеры получают отдельные подходящие mount'ы. Одно место остаётся для управления/ревью; при нехватке свободных мест выделение ждёт. Незакоммиченная или неотправленная работа сохраняется. Перед отправкой проверяются владелец lease, ветка и точная ревизия. Исходный mount не переключается на ветку задачи.

Токен Tracker читается из `TRACKER_OAUTH_TOKEN`, `TRACKER_TOKEN` или `~/.tokens/tracker`. Тикет вида `TEAM-123` импортируется для чтения; комментарии в Tracker инструмент не пишет. Нативное ревью использует Arcanum и Arc. Описания тикетов и Markdown опубликованных замечаний сохраняются.

```bash
daddy new --workspace Work "TEAM-123"
daddy talk SESSION_ID "Возьми ещё TEAM-124"
```

Ревью и реализация идут по [общему циклу задачи](../tasks/ru.md). Чистый lease реализации можно освободить после подтверждения точной ревизии в нативном PR. Неопубликованная или изменённая работа защищена. Очистка описана в [эксплуатации](../operations/ru.md).
