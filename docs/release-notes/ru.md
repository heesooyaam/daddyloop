# daddyloop 0.13.1

Уточнена русская подсказка в чате: «С тебя задача. Остальное папочка берёт на себя».

## 0.13.0

- Модуль Claude: выполнение через настоящий CLI/SDK, каталог моделей и effort, ограниченные MCP-инструменты, возобновление и отмена, API-ключ и отдельный компонент установщика.
- Usage принадлежит адаптерам агентов. Отдельные квоты моделей, аккаунты только с недельным окном, планы с кредитами, неизвестные/старые показания и подтверждаемые сбросы используют общий интерфейс.
- Переносимые бэкапы сохраняют записи workflow, Git-источники и рабочие копии, а также экспорт задач Arcadia. Восстановление проверяет хеши, меняет пути и ставит незавершённое на паузу.
- В README главный Mint-скриншот, заметный Telegram и голос папочки. Добавлены парные инструкции по Claude, бэкапам и разработке модулей; подключение ноутбука/телефона объяснено со схемами.

Актуальны конфиг 3 и SQLite 7. Usage API теперь возвращает `{ agents: [...] }`; обновляй клиенты вместе с приложением. Бэкап этого формата следует восстанавливать той же версией приложения. Для запросов моделей нужна своя авторизация у провайдера.

## Ранее: 0.12.0

- Название worker заменяет writer в API, CLI, настройках, пуле и интерфейсе. Алиасов прежнего имени нет.
- Восемь тем сайта, включая четыре тёмные; выбор хранится в браузере и может следовать системной теме.
- Периоды usage Codex и остаток сбросов постоянно видны под заголовком на компьютере и телефоне.
- Реестры агентов и репозиториев направляют работу через явные контракты. Галочки установщика определяют интеграции и дополнительные загрузки CLI.
- Документация парная по темам: `docs/<тема>/en.md` и `ru.md`, включая доступ к сайту с компьютера и телефона. Оба корневых README ведут в одну структуру.
- Тексты daddy приведены к прямому неформальному голосу.

Несовместимое изменение данных: конфиг 3 / SQLite 7. Для существующей установки нужно явное преобразование с резервной копией: имена полей профилей/пула, пути исполняемых файлов и привязка сессий к движкам. Обновление приложения и смена модулей перезапускают сервис; прерванную работу нужно проверить и продолжить. Вход браузера и привязка Telegram могут быть сохранены при преобразовании.
