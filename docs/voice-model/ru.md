# Источник модели речи

Релиз использует квантованный ONNX-экспорт **Whisper Small** из `onnx-community/whisper-small`, ревизия `36050c46d777d46dc4b5f43f6d90574fc38f8732`. Точный список файлов, размеры и SHA-256 закреплены в `scripts/speech-model.json` и проверяются `scripts/prepare-speech.mjs`.

Файлы модели занимают примерно 240 МиБ. Распознавание выполняется на CPU через Transformers.js и ONNX Runtime. OGG/Opus Telegram декодируется локально. Модель скачивается при подготовке релиза или исходников, а не для каждого голосового.

Экспорт модели указывает лицензию Apache-2.0. [Оригинал лицензии](../licenses/Apache-2.0.txt) сохранён без изменения. У пакетов зависимостей собственные лицензионные уведомления. Ограничения и поведение описаны в [голосовых](../voice/ru.md).
