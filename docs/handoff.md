# Продолжение работы

Рабочий каталог: `/home/heesooyaam/projects/reviewloop`. Это самостоятельный Git-проект с веткой `main`, локальным Node 24, backend, runner, UI, CLI, документацией и тестами.

## Что проверить утром

1. Открыть `http://127.0.0.1:4317` через SSH-туннель. Токен — `./scripts/reviewctl.mjs token` из каталога проекта.
2. Посмотреть демонстрационную задачу; обсуждение, публикация и повторный проход доступны без внешних аккаунтов.
3. Добавить `~/.tokens/github` и `~/.tokens/gitlab` (либо соответствующие env variables). Для self-hosted GitLab указать его host.
4. Выполнить `./scripts/reviewctl.mjs doctor`, затем `./scripts/reviewctl.mjs create-remotes --name reviewloop --push`.
5. После подключения выбрать отдельный тестовый PR/MR и проверить native drafts, редактирование через reviewer session, ручную публикацию, автоматические исправления и повторное ревью на новой SHA.

Документы для продолжения: [README](../README.md), [архитектура](architecture.md), [ревью и результаты проверки](review.md), [эксплуатация и ограничения](operations.md).

Не превращать локальную демонстрацию или HTTP fixtures в утверждение о проверенной живой GitHub/GitLab-интеграции. Лицензию и публичную видимость проекта выбирает владелец перед публикацией; подготовленная команда создаёт private repositories.
