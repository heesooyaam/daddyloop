# Состояние установки 0.2

Сервер и оба агента работают на одной машине. Доступ с ноутбука и телефона — клиентский. Исполняемый релиз устанавливается отдельно от исходников; данные прежней установки сохраняются.

Проверить состояние: `reviewctl service status`, `reviewctl doctor`, `reviewctl`.

Остаются действия владельца внешних аккаунтов:

1. Изменить видимость GitHub-репозитория на public, чтобы публичная команда установки могла скачать релиз.
2. Выполнить `reviewctl web tailscale` и войти в сеть, затем поставить Tailscale на телефон и получить ссылку через `reviewctl phone`. Можно вместо этого настроить свой HTTPS-прокси.
3. Создать бота в BotFather и выполнить `reviewctl telegram setup`.
4. При необходимости подключить GitLab: `reviewctl auth gitlab`.
5. Выбрать отдельный тестовый PR/MR для живой проверки native draft → publish → fix → push. Демонстрационные задачи и HTTP fixtures этого не заменяют.

Не менять ветки и пользовательские правки в исходном Arcadia mount. Подробные результаты и ограничения: [ревью 0.2](review-v0.2.md), [эксплуатация](operations.md).
