# Ревью реализации · 2026-09-08

Проведено ревью нового проекта по сценарию из исходного обсуждения: общий цикл для плана и кода, постоянные отдельные сессии, native-черновики от имени пользователя, обсуждение через ревьюера и передача только опубликованного набора автору. Проверка была сосредоточена на корректности переходов, сохранности пользовательских решений, повторных внешних действиях и ресурсах.

## Найдено и исправлено

| Важно   | Черновые решения могли попасть к автору через общий журнал контекста                                                | Автору передаются только решения, связанные с опубликованными комментариями; тест приватности                         |

При проверке также подтверждены: ручной и автоматический режимы публикации, сохранение точного Markdown и ручных удалений, запрет авторской self-verification, лимит раундов, ожидание актуального CI, отдельное согласование плана, запись принятого Markdown-плана и GitLab partial-publication guard.

## Выполненные проверки

- **50 тестов** в 8 файлах: workflow, worker, SQLite, outbox, Git workspaces, HTTP provider contracts, API и Codex protocol fixtures — прошли.
- **2 браузерных теста**: полный demo-цикл с обсуждением и двумя публикациями; мобильная форма и отсутствие горизонтального overflow — прошли.
- TypeScript strict typecheck и production build — прошли.
- Живой `codex-cli 0.153.4`: dynamic tool round trip, валидный structured result и память между двумя turns одного сохранённого thread — прошли. Проверка повторена после явного задания workspace roots.
- `reviewctl doctor` подтвердил Codex authentication и отсутствие локальных credentials платформ.
- `create-remotes` корректно отложил оба шага, не создавая фиктивные remotes.
- После установки зависимостей npm сообщил 0 известных уязвимостей.

## Практические границы проверки

**Живой GitHub/GitLab draft/edit/publish/push ещё не проверен:** для локального приложения нет соответствующих токенов. Это остаётся необходимым следующим шагом до использования с реальными задачами. Конфигурации CI подготовлены, но удалённые CI не запускались, поскольку репозитории ещё не созданы.

Тесты не доказывают надёжность произвольных корпоративных конфигураций Codex, GitLab и GitHub Enterprise. В частности, ambiguous native writes и GitLab-комментарии с удалёнными markers намеренно требуют человеческой сверки; полноценный интерфейс разрешения неоднозначных операций в этой версии отсутствует. Остальные границы описаны в [operations.md](operations.md).

Проверки ресурсов выполнялись в процессе работы. После сборок и браузерных тестов на хосте оставалось примерно **44 GiB доступной RAM и 182 GiB диска**. Порог очистки `/home` не достигался. Чужие процессы, рабочие копии и кеши не удалялись; тестовые браузеры и запущенные для проверок Codex subprocesses закрыты.
