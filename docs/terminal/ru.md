# CLI daddy

Запусти `daddy`, чтобы открыть интерактивную консоль. В ней один разговор с daddy, доска задач, выбор воркспейса, пул воркеров и настройки моделей.

`daddy` — клиент фонового сервиса. Два терминала подключаются к одним сессиям, задачам и отправленным сообщениям. Через `/sessions` или `daddy console SESSION_ID` можно открыть один и тот же разговор или разные сессии. Неотправленный черновик остаётся в своём клиенте. Закрытие терминала не останавливает агентов.

Если подключена Telegram-группа с темами, сессия из CLI автоматически получает свою тему. Твои отправленные сообщения появляются там с подписью `[user]`, реплики и ответы daddy — с `[daddy]`. Ответ из этой темы попадает в тот же разговор в CLI и на сайте. [Настройка Telegram](../telegram/ru.md).

| Команда                        | Назначение                                              |
| ------------------------------ | ------------------------------------------------------- |
| `/new`, `/workspaces`          | Выбрать воркспейс и начать работу                       |
| `/sessions`                    | Переключить сессию                                      |
| `/tasks`, `/chat`              | Переключить доску задач и разговор                      |
| `/pool`, `/pool 3`             | Посмотреть или изменить пул воркеров                    |
| `/models`                      | Выбрать модель с указанием движка и глубину рассуждений |
| `/repo /путь`, `/repo default` | Задать или отменить разовый репозиторий                 |
| `/limits`                      | Посмотреть квоты и подготовить подтверждаемый сброс     |
| `/notifications`, `/updates`   | Уведомления и версии CLI                                |
| `/language en`, `/language ru` | Язык                                                    |
| `/pause`, `/resume`            | Управление сессией                                      |
| `/quit`                        | Закрыть этот клиент                                     |

`/instructions` показывает наборы обеих ролей; `/instructions daddy <текст>`, `/instructions worker <текст>` и `/skill <роль> <ссылка GitHub>` меняют только выбранную сессию. [Инструкции, импорт и бекапы](../instructions/ru.md).

Ctrl+N начинает сессию, Ctrl+T выбирает её, Tab меняет панель, PgUp/PgDn прокручивают, Ctrl+Q выходит. Enter отправляет текст; интерфейс показывает доступные сочетания. При переключении сессий внутри клиента черновики хранятся отдельно.

```bash
daddy --theme dark
daddy --theme light
daddy --plain
daddy console SESSION_ID
daddy talk SESSION_ID "Возьми следующий тикет"
```

Обычная текстовая консоль — базовый клиент того же daddy. Закрытие любой консоли восстанавливает режимы терминала и оставляет сервис работать. Восемь тем сайта хранятся отдельно в браузере — см. [внешний вид](../web/ru.md#темы).

Для CLI на другой машине собери клиент из исходников с поддерживаемой версией Node, затем выполни `daddy connect https://твой-хост` и введи токен. Сайту локальный Node не нужен: [открыть с компьютера](../web/ru.md).

`/presets` показывает общие пресеты инструкций, `/preset <название>` подключает один к этой сессии. В полном CLI есть `daddy presets save/show/delete` и повторяемый флаг `--preset`. [Инструкция по пресетам](../instructions/ru.md).

`/delete` открывает подтверждение удаления сессии с собственными копиями. Команда CLI — `daddy delete SESSION_ID --yes`. При регистрации воркспейса Arcadia или запуске новой сессии можно выбрать `--copies session` либо `--copies pool`; см. [Arcadia](../arcadia/ru.md).
