# Скриншоты продукта

Картинки в `docs/media/` показывают настоящие сайт и Ink-терминал на изолированных примерах. Ответы по задачам, квоты и каталоги моделей на них — иллюстративные данные. Это не приватные разговоры пользователя и не доказательство записи в реальный PR.

```bash
npm run build
node scripts/capture-daddy.mjs
```

Скрипт снимает компьютер, телефон, настройки и темы. Он также запускает реальный CLI в PTY и воспроизводит ANSI-вывод через xterm.js. После закрытия клиента проверяются режимы терминала и PID сервиса. Размер телефонных кадров — 390 × 844; отдельный браузерный тест проверяет HTTPS-привязку и отключение ноутбука.

После изменения текста, раскладки или цветов переснимай интерфейс. Старым скриншотам не место в актуальных инструкциях. Не снимай токены, настоящие личные переписки бота или содержимое рабочих корпоративных задач.

Главная картинка README — снимок Mint. `node scripts/capture-telegram.mjs` рисует иллюстрацию Telegram из сущностей `TelegramText` и локальных шрифтов, без обращения к Telegram.
