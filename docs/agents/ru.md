# Модули агентов и модели

**Движок** — установленный модуль агента. **Модель** и глубина рассуждений принадлежат этому движку. У daddy и воркеров независимые профили. Планировщик отправляет работу через `AgentRuntime` / `SessionRuntime`: он не разбирает названия моделей и не говорит на протоколе конкретного CLI.

Поставляются **Codex и Claude**. У них [общий контракт](../modules/ru.md); daddy может управлять воркерами на другом движке. [Подключение Claude](../claude/ru.md).

```bash
daddy models --refresh
daddy agents defaults \
  --worker-engine codex --worker-model gpt-5.6-sol --worker-effort max \
  --daddy-engine codex --daddy-model gpt-6-astra --daddy-effort max
```

Используй идентификаторы моделей, которые действительно вернул `daddy models`. Названия выше — пример, а не список, вручную поддерживаемый продуктом. Модуль Codex читает `model/list` из выбранного CLI, проходит страницы и кеширует успешный ответ на пять минут. Обновление списка делает новый запрос. Глубина рассуждений берётся из ответа CLI; новые значения не отсекаются локальным списком.

На сайте открой **Настройки сессии**. Для daddy и будущих воркеров выбираются модуль, модель и глубина рассуждений. В CLI и боте — `/models`; у каждого варианта указан движок. Новые дефолты воркеров применяются к будущим задачам. Для смены daddy нужна свободная сессия. При смене движка прежние идентификаторы контекста записываются в историю, а нативный контекст создаётся заново: сессия Codex не передаётся другому runtime.

## Версии CLI

```bash
daddy updates --check
daddy runtime update --engine claude --yes
daddy runtime update --engine codex --yes
daddy runtime rollback --engine claude --yes
daddy runtime update-status
```

Открой **Обновления** на сайте или `/updates` в Telegram. У каждого установленного адаптера — своя версия, обновление и откат. Если CLI несколько, в терминале нужно указать `--engine`. Модуль без установщика может сообщить о релизе, но интерфейс предложит инструкции по установке вместо неработающей кнопки.

Подтверди показанные старую и новую версии. Сервис скачает официальный пакет, проверит контрольную сумму, установит его в отдельную неизменяемую папку и проверит CLI, каталог моделей и сохранённые профили этого движка. Если проверка не пройдёт, останется выбранная версия. Уже запущенные агенты закончат на своём исполняемом файле; следующие ходы получат новую версию. На завершённую операцию приходит одно сообщение, без второго уведомления о той же смене версии.

Управляемые обновления Codex и Claude Code работают на Linux x64/ARM64; Claude нужен glibc. Если CLI задан переменной окружения сервиса, обновление отключено с объяснением. Обновление CLI не заменяет адаптер и SDK daddyloop: несовместимая версия отклоняется при проверке.

Выбрать другой исполняемый файл на сервере:

```bash
daddy runtime use /полный/путь/к/claude --engine claude
daddy runtime use bundled --engine codex
```

`use` проверяет CLI через выбранный адаптер и принадлежность сервиса этой установке. Перезапуск разрешён, только когда нет запущенных или ожидающих задач и обновлений. `daddy doctor` проверяет включённые адаптеры без обращения к модели. Общий контракт описан в [разработке модулей](../module-development/ru.md), квоты — в [настройках интерфейса](../appearance/ru.md).

## Реальные квоты аккаунта

`daddy limits --refresh` и постоянная панель сайта объединяют данные включённых адаптеров. Модуль Codex вызывает `account/rateLimits/read`: использует `rateLimitsByLimitId` и при необходимости сохраняет дополнительную основную квоту. Показываются только пришедшие окна, их `windowDurationMins`, `usedPercent`, `resetsAt`, название, тариф и кредиты. Если аккаунт вернул только неделю, будет только неделя. Квоты отдельных моделей, в том числе Spark, когда он есть в ответе, показываются отдельно. Таблицы «подписка → периоды» в приложении нет.

Количество сбросов берётся из `availableCount`; отсутствие подробных строк не означает нулевой остаток. Сброс требует подтверждения и повторно использует ключ идемпотентности. Usage Claude следует возможностям его событий; неизвестные и старые показания отмечаются явно. См. [протокол Codex](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt) и [лимиты Claude](../claude/ru.md).

Несовместимое изменение протокола CLI может сделать usage недоступным. Адаптер покажет ошибку и отметит кэш как устаревший; свежий процент не выдумывается, сброс по старым данным не предлагается. Изменения протокола исправляются в адаптере.
