# Модули агентов и модели

**Движок** — установленный модуль агента. **Модель** и глубина рассуждений принадлежат этому движку. У daddy и воркеров независимые профили. Планировщик отправляет работу через `AgentRuntime` / `SessionRuntime`: он не разбирает названия моделей и не говорит на протоколе конкретного CLI.

Сейчас поставляется рабочий модуль **Codex**. Адаптер Claude пока не поставляется. Общий [контракт модулей](../modules/ru.md) позволяет добавить другой движок, не создавая второй оркестратор.

```bash
daddy models --refresh
daddy agents defaults \
  --worker-engine codex --worker-model gpt-5.6-sol --worker-effort max \
  --daddy-engine codex --daddy-model gpt-6-astra --daddy-effort max
```

Используй идентификаторы моделей, которые действительно вернул `daddy models`. Названия выше — пример, а не список, вручную поддерживаемый продуктом. Модуль Codex читает `model/list` из выбранного CLI, проходит страницы и кеширует успешный ответ на пять минут. Обновление списка делает новый запрос. Неподдерживаемый режим делегирования исключён.

На сайте открой **Настройки сессии**. Для daddy и будущих воркеров выбираются модуль, модель и глубина рассуждений. В CLI и боте — `/models`; у каждого варианта указан движок. Новые дефолты воркеров применяются к будущим задачам. Для смены daddy нужна свободная сессия. При смене движка прежние идентификаторы контекста записываются в историю, а нативный контекст создаётся заново: сессия Codex не передаётся другому runtime.

## Версии CLI

```bash
daddy updates --check
daddy runtime update --yes
daddy runtime rollback --yes
```

В Telegram используй `/updates`. Подтверждённое обновление фиксирует версию и проверяет пакет, протокол CLI и сохранённые профили Codex. Уже работающие процессы продолжают использовать свой исполняемый файл; следующий ход получает новую версию. Приходит одно сообщение о результате. Потерянный ответ сначала восстанавливается, затем разрешается следующая операция.

Чтобы выбрать установленный на хосте Codex, используй `daddy runtime use /полный/путь/к/codex`. Команда проверяет CLI и перезапускает свободный сервис. `daddy runtime use bundled` выбирает установленный модуль Codex. Эти команды управления — отдельные возможности Codex, а не часть общего механизма отправки задач агентам.

Квоты аккаунта и подтверждаемые сбросы описаны во [внешнем виде и usage](../appearance/ru.md).
