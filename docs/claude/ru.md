# Claude в бригаде папочки

Выбери `claude` в установщике. Он поставит Claude Code CLI отдельным компонентом; в общей части находится транспорт официального Agent SDK. Для команд в Linux нужны Bubblewrap и socat — установщик добавляет их на поддерживаемых системах с apt. Если песочница недоступна, команды не запускаются без ограничений.

## Подключить аккаунт

На машине с сервисом:

```bash
daddy auth agent claude
# Или прочитать уже сохранённый приватный ключ:
daddy auth agent claude --token-file /private/anthropic-key
daddy models --refresh
```

Скрытый ввод сохраняет Anthropic API-ключ в `~/.tokens/anthropic` с приватными правами. Переменная `ANTHROPIC_API_KEY` в окружении сервиса имеет приоритет; `DADDYLOOP_CLAUDE_API_KEY_FILE` позволяет выбрать другой приватный файл. Ключ остаётся на сервере и исключается из окружения команд внутри песочницы агента.

Интеграция использует [официальный Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview). Его документированный способ авторизации приложения — через API. Подписка Claude Pro/Max не является балансом API; обходного входа через подписку daddyloop не предлагает.

## Выбрать роль и модель

Открой **Настройки сессии → Модели** на сайте или `/models` в CLI либо Telegram. Выбери **Claude** для daddy, воркеров или обеих ролей. Движки можно смешивать: например, daddy на Codex, воркеры на Claude.

Каталог запрашивается у установленного CLI через `supportedModels()`. Передаются его ID моделей, в том числе алиасы вроде `sonnet[1m]`, если они есть в ответе, и поддерживаемые effort-уровни. Успешный ответ хранится пять минут; обновление каталога запрашивает его заново. Наличие модели в каталоге не гарантирует доступ аккаунта: провайдер проверяет его при запуске.

Дефолты воркеров действуют на новые задачи. Смена движка daddy требует свободной сессии и начинает новый внутренний контекст агента. Переписка daddyloop и записи задач сохраняются.

## Работа и лимиты

Claude получает отдельную рабочую папку, правила роли и инструменты daddyloop через MCP-сервер внутри приложения. Результат имеет тот же формат, что у Codex. ID сессий сохраняет и возобновляет адаптер Claude. Отмена закрывает запрос; отсутствующий, ошибочный или некорректный результат не продвигает задачу дальше.

Воркеры могут менять свою рабочую копию. Ревью и координация выполняются в режиме чтения. Нативные подагенты и произвольные MCP-подключения исключены: папочка раздаёт работу через общий интерфейс воркеров. Публикация ревью по-прежнему проходит проверки ревизии и владельца в daddyloop.

Usage берётся из событий CLI `rate_limit_event`, когда они приходят. Адаптер сохраняет названия квот, время сброса и использование из ответа провайдера. Нет события или процента — **данные неизвестны**, а не «осталось 100%». Через две минуты показания считаются устаревшими; кнопка обновления не может заставить Claude предоставить отсутствующий API запроса квот. Расход по моделям за ход и оценка стоимости API сохраняются в событиях запуска. Панель usage также показывает входные/выходные токены и оценку стоимости последнего сообщённого хода агента; это не баланс аккаунта. Действие сброса квот адаптер Claude не предоставляет.

## Версии и ошибки

В релизе SDK `0.3.268` используется с Claude CLI `2.1.268`. Исполняемый файл фиксируется на время хода. `daddy updates --check` показывает смену версии CLI и новые релизы. Кнопки управляемого обновления и отката сейчас обновляют Codex; встроенный Claude обновляется с релизом daddyloop. Также можно указать проверенный исполняемый файл в `executables.claude` и перезапустить свободный сервис.

- **Ошибка авторизации:** проверь API-ключ на сервере и оплату API-аккаунта.
- **Нет моделей:** выполни `daddy models --refresh`; изучи ошибку CLI, не публикуя ключи и токен-файлы.
- **Песочница недоступна:** установи Bubblewrap и socat, проверь разрешение user namespaces на хосте. Не включай обход разрешений.
- **Неверный результат / лимит ходов:** задача остаётся незавершённой; изучи сохранённые события и продолжи после устранения причины.

См. [профили агентов](../agents/ru.md), [разработку модулей](../module-development/ru.md) и [бэкапы](../backups/ru.md).

Для явной живой проверки из исходников выполни `DADDYLOOP_LIVE_CLAUDE_TEST=1 npx tsx scripts/smoke-claude.ts` после авторизации и настройки песочницы. Скрипт делает два платных API-запроса во временной папке, проверяет создание файла, продолжение нативной сессии и MCP-вызовы, задаёт бюджет SDK $0.25 на вызов. Обычные тесты его не запускают.
