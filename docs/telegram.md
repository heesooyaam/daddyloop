# Reviewloop в Telegram

Бот присылает компактные карточки: статус, название задачи, итог, текущий раунд и проверки. Например:

> ✅ **Задача завершена**
>
> **Защита от устаревших callback**
>
> **Готово:** старый callback больше не меняет новую сессию.
>
> • Добавлена проверка поколения.  
> • Регрессионный тест покрывает замену сессии.  
> • Повторное ревью завершено без замечаний.
>
> Раунд 2 · Замечаний: 0 · CI: пройдены  
> Задача `a1b2c3d4`

Под сообщением доступны **Статус** и **Задачи**. Для рабочих задач есть ссылка на PR или тикет, для настроенного HTTPS-сайта — ссылка на рабочее пространство. Демо помечено отдельно. Подтверждённое исключение CI отображается как исключение, а не как успешная проверка.

## Ответы агентов

Переписка различает **Ответ автора** и **Ответ ревьюера**. Поддерживаются жирный текст, курсив, зачёркивание, списки, чекбоксы, ссылки и блоки кода с указанием языка. Таблицы показываются моноширинным текстом. Длинный ответ продолжается в следующих сообщениях: текст не обрезается, разметка сохраняется, кнопки находятся в конце.

Форматирование применяется только к отображению в Telegram. Сохранённый текст разговора и Markdown нативных замечаний остаются исходными. HTML из названий и сообщений отображается буквальным текстом. Служебные комментарии `<!-- reviewloop:… -->` скрыты только в отображении; в примерах кода они сохраняются.

## Кнопки и команды

- **Задачи** или `/tasks`: список по пять задач на страницу. Нажми название для текущего статуса.
- **Уведомления** или `/notifications`: тихий режим, все ответы либо выключение. Выбранный режим отмечен галочкой.
- **Опубликовать ревью…**: открывает отдельное подтверждение. Публикация выполняется только после второго нажатия; изменение ревизии или текста ревью отменяет старое подтверждение.
- `/language`: русский или английский для интерфейса рабочего пространства.
- `/models`: текущие профили, живой каталог моделей и кнопка обновления. Выбор модели доступен в TUI и на сайте.
- `/updates`: версии CLI, обновление Codex на сервере, откат и настройки уведомлений. Нажми «Обновить Codex» и подтверди конкретную версию. Установка продолжится, даже если закрыть Telegram; бот сообщит результат. [Как устроено обновление →](models-and-updates.md#обновить-codex-с-телефона)
- `/help`: команды с примерами. Идентификаторы и команды можно копировать как код.
- `/web`: одноразовая ссылка входа на настроенный HTTPS-сайт.

Все кнопки проверяют привязанный личный чат и пользователя. Для новых задач публикация остаётся автоматической; ручная кнопка появляется у задач с ручной политикой.

Подключение: `reviewctl telegram setup`. По умолчанию уведомления приходят о завершении или когда нужно решение человека. `/notifications all` включает промежуточные ответы. [Установка и привязка](getting-started.md#telegram).
